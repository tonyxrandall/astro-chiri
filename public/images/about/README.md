# About page images

Pages CMS writes the about page hero image here.

If an upload fails with `413`, the image is too large for the CMS upload request. Export a smaller web image before uploading:

- Resize the long edge to about 1600–2000px.
- Save as JPG or WebP.
- Keep the file under roughly 4 MB.

The image shown in Pages CMS can then be selected for the About page `Profile / Feature Image` field.
