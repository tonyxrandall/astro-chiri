# Blog images

Pages CMS writes blog cover images here.

If an upload fails with `413`, the CMS upload request is larger than the server will accept. Export a smaller web image before uploading:

- Resize the long edge to about 1600–2000px.
- Save as JPG or WebP.
- Keep the file under roughly 4 MB.

After the optimized image uploads, select it in the Blog Post `Cover Image` field.
